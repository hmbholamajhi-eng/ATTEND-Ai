# 📌 Project Overview

AttendAI is a modern AI-powered attendance management system designed for college and university students.

Instead of manually calculating attendance, AttendAI automatically tracks classes, predicts attendance percentage, calculates safe bunks, manages timetables, generates reports, and provides intelligent insights.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/hmbholamajhi-eng/ATTEND-Ai.git
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Build

```bash
npm run build
```
